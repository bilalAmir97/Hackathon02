# Quickstart Guide: Backend Core & Data Layer

**Feature**: 003-todo-backend-core
**Date**: 2026-01-11
**Phase**: Phase 1 - Local Development Setup

## Overview

This guide walks you through setting up the FastAPI backend locally for development and testing.

## Prerequisites

- **Python**: 3.13+ (constitution requirement)
- **UV**: Python package manager (install: `curl -LsSf https://astral.sh/uv/install.sh | sh`)
- **Neon PostgreSQL**: Database account (free tier: https://neon.tech)
- **Git**: Version control

## Setup Steps

### 1. Create Project Directory

```bash
# From repository root
mkdir -p Phase-II/backend
cd Phase-II/backend
```

### 2. Initialize UV Project

```bash
# Initialize Python project with UV
uv init --python 3.13

# Install dependencies
uv add fastapi sqlmodel asyncpg pydantic python-dotenv uvicorn

# Install dev dependencies
uv add --dev pytest pytest-asyncio httpx pytest-cov ruff
```

### 3. Configure Neon PostgreSQL

**Create Database**:
1. Sign up at https://neon.tech (free tier)
2. Create a new project: "todo-backend-dev"
3. Copy the connection string (format: `postgresql://user:pass@host/db`)

**Get Connection String**:
- Navigate to your Neon project dashboard
- Click "Connection Details"
- Select "Connection string" tab
- Copy the connection string
- **Important**: Add `?sslmode=require` to the end

**Example Connection String**:
```
postgresql://user:password@ep-xxx-xxx.region.aws.neon.tech/neondb?sslmode=require
```

**For Async (asyncpg driver)**:
```
postgresql+asyncpg://user:password@ep-xxx-xxx.region.aws.neon.tech/neondb?sslmode=require
```

### 4. Create Environment Configuration

Create `.env` file in `Phase-II/backend/`:

```bash
# Copy example file
cp .env.example .env

# Edit .env with your values
```

**`.env` contents**:
```env
# Database Configuration
DATABASE_URL=postgresql+asyncpg://user:password@host/db?sslmode=require

# Database Pool Settings
DATABASE_POOL_SIZE=10
DATABASE_MAX_OVERFLOW=20

# Application Settings
APP_ENV=development
LOG_LEVEL=INFO

# API Settings
API_HOST=0.0.0.0
API_PORT=8000
```

**`.env.example` contents** (commit this to git):
```env
# Database Configuration
DATABASE_URL=postgresql+asyncpg://user:password@host/db?sslmode=require

# Database Pool Settings
DATABASE_POOL_SIZE=10
DATABASE_MAX_OVERFLOW=20

# Application Settings
APP_ENV=development
LOG_LEVEL=INFO

# API Settings
API_HOST=0.0.0.0
API_PORT=8000
```

### 5. Create Test Database Configuration

Create `.env.test` for testing:

```env
# Test Database (use Neon branch or separate database)
TEST_DATABASE_URL=postgresql+asyncpg://user:password@host/test_db?sslmode=require

# Test Settings
APP_ENV=test
LOG_LEVEL=DEBUG
```

**Neon Database Branching** (recommended for testing):
1. In Neon dashboard, create a branch: "test"
2. Use the branch connection string for `TEST_DATABASE_URL`
3. Tests run against isolated database copy

### 6. Verify Setup

**Check Python version**:
```bash
python --version
# Should show: Python 3.13.x
```

**Check UV installation**:
```bash
uv --version
```

**Test database connection**:
```bash
# Create a test script: test_connection.py
cat > test_connection.py << 'EOF'
import asyncio
from sqlalchemy.ext.asyncio import create_async_engine
import os
from dotenv import load_dotenv

load_dotenv()

async def test_connection():
    engine = create_async_engine(os.getenv("DATABASE_URL"))
    async with engine.connect() as conn:
        result = await conn.execute("SELECT 1")
        print("✅ Database connection successful!")
    await engine.dispose()

asyncio.run(test_connection())
EOF

# Run test
uv run python test_connection.py
```

Tests automatically:
1. Create test database schema before each test session
2. Clean up after tests complete
3. Use transactions for test isolation

**Manual test database reset** (if needed):
```bash
# Drop and recreate test database
uv run python -c "
from src.database import engine
from src.models import SQLModel
import asyncio

async def reset_db():
    async with engine.begin() as conn:
        await conn.run_sync(SQLModel.metadata.drop_all)
        await conn.run_sync(SQLModel.metadata.create_all)

asyncio.run(reset_db())
"
```

## API Usage Examples


## Troubleshooting

### Database Connection Issues

**Error**: `connection refused` or `timeout`
- **Solution**: Check DATABASE_URL is correct
- **Solution**: Verify Neon database is running (check dashboard)
- **Solution**: Ensure `?sslmode=require` is in connection string

**Error**: `asyncpg.exceptions.InvalidPasswordError`
- **Solution**: Regenerate password in Neon dashboard
- **Solution**: Update DATABASE_URL in .env

### Import Errors

**Error**: `ModuleNotFoundError: No module named 'fastapi'`
- **Solution**: Run `uv sync` to install dependencies
- **Solution**: Ensure you're using `uv run` prefix for commands

### Port Already in Use

**Error**: `Address already in use`
- **Solution**: Kill process on port 8000: `lsof -ti:8000 | xargs kill -9`
- **Solution**: Use different port: `uvicorn src.main:app --port 8001`

### Test Database Issues

**Error**: Tests fail with database errors
- **Solution**: Ensure TEST_DATABASE_URL is set in .env.test
- **Solution**: Use separate Neon branch for testing
- **Solution**: Run `pytest --create-db` to recreate test database
