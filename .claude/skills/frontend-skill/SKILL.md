# Frontend Skill

## Instructions

1. **Page & Routing Structure**
   - Design clear page hierarchy (home, auth, dashboard, settings).
   - Implement client-side or hybrid routing (CSR/SSR/SSG as required).
   - Apply layout wrappers (public vs authenticated pages).

2. **Component Architecture**
   - Build reusable, composable components (buttons, inputs, modals, cards).
   - Separate presentational components from stateful/container components.
   - Use props, slots, and composition instead of duplication.

3. **Layout Systems**
   - Use CSS Grid and Flexbox for responsive layouts.
   - Define global layout primitives (header, sidebar, footer).
   - Support multiple breakpoints (mobile, tablet, desktop).

4. **Styling & Theming**
   - Apply consistent design tokens (colors, spacing, typography).
   - Use utility-first CSS (Tailwind) or scoped styles (CSS Modules).
   - Implement light/dark themes and accessible color contrast.

5. **State & UI Behavior**
   - Manage local and global state (hooks, context, stores).
   - Handle loading, empty, and error states explicitly.
   - Ensure smooth UI feedback for user actions.

6. **Performance & Optimization**
   - Code-split pages and heavy components.
   - Optimize images, fonts, and third-party scripts.
   - Minimize re-renders and avoid unnecessary state.

7. **Accessibility & UX**
   - Use semantic HTML and ARIA attributes where needed.
   - Ensure keyboard navigation and focus management.
   - Follow WCAG guidelines for contrast and interactions.

8. **Testing & Consistency**
   - Write component tests and visual regression tests.
   - Enforce linting and formatting rules.
   - Maintain a shared component library or design system.

## Best Practices
- Keep components small and single-responsibility.
- Prefer composition over inheritance.
- Mobile-first layouts with progressive enhancement.
- Avoid inline styles for scalable systems.
- Use consistent spacing and typography scales.
- Document components and props clearly.
